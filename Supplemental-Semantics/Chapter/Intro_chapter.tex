\gloss{system}{machine controlled by software}

Simple machines need no electronics nor software to function.
Simple machines need no systems engineering nor systems modeling language.
Consequently, the purpose of SysML \cite{SysML} shall be to design systems as defined above.

KerML \cite{KerML} is intended to be used as the basis for modeling languages other for modeling systems.
Nevertheless, the supplementary formal semantics are intended to support SysML to design systems.

Part \ref{part:kerml} defines formal semantics for KerML.

Part \ref{part:sysml} uses the semantics from Part \ref{part:kerml} to define formal semantics for SysML v2.
